# WealthTrace - Kişisel Finans ve Yatırım Takip Sistemi

Bu proje, Spring Boot ve React kullanılarak geliştirilmiş modern bir finans yönetim uygulamasıdır.

## Teknik Özellikler
- **Backend:** Java 17, Spring Boot, Spring Security (JWT)
- **Database:** PostgreSQL & Redis
- **Container:** Docker & Docker Compose
- **Özellikler:** Varlık takibi, API entegrasyonu, PDF raporlama.

## Kurulum
1. `docker-compose up` komutu ile veritabanını başlatın.
2. Backend klasöründe `./mvnw spring-boot:run` komutunu çalıştırın.
